# PHAGOS — Dermal Rift Expedition

PHAGOS is a native **Godot 4.3 2D exploration-adventure project**. Godot is the source of truth for rendering, camera, player movement, collision, dynamic routes, UI, and gameplay. The browser/WebView preview runs the **same Godot project** after a Web export.

```text
Godot scene + GDScript + authored organ data
                 ↓
player / collision / dynamic organ-state runtime
                 ↓
Godot Web export
                 ↓
build/web/index.html + index.wasm + index.pck
                 ↓
static server → WebView
```

The game is not a repository page, React wrapper, iframe, or standalone HTML recreation.

## Play the current vertical slice

**Dermal Rift** is now a playable exploration loop, not a static skin image:

- Move a native Godot **Traversal Cell** with **WASD** or **arrow keys**; hold **Shift** to sprint.
- Explore collidable cavity routes and discover named anatomical landmarks.
- Read the living route: active tissue states open, collapse, shift, and narrow different routes.
- The state director previews a change before committing collision and will delay a shift if the explorer is not safely inside a connected chamber.
- Find the **Deep Cavity**, press **E / Enter** to read its pulse, then navigate to the unlocked **Organ Gate** and cross it.
- Press **Tab** or **M** to fold/open the discovered-map affordance; press **R** to request a safe tissue pulse for review.

The first playable organ has five authored states:

```text
resting → contraction → vascular surge → inflammation → recovery
```

Each state reads `data/organ_biomes/dermal_rift.json`, changes active routes and movement envelopes, and retains a valid entry-to-exit path. The visual world and `StaticBody2D` cavity collision are generated by the same native Godot runtime data.

## Run in WebView

A current Godot Web payload is committed under `build/web/` for immediate preview:

```bash
./scripts/preview_web.sh
```

Open:

```text
http://127.0.0.1:8008
```

The helper serves **only** `build/web/`. Do not open a repository/PR page as the game, and do not serve a standalone app shell around it.

To create a fresh export after Godot changes:

```bash
./scripts/export_web.sh --release
```

## Develop with Godot

On a desktop machine with Godot 4.3 installed:

```bash
./scripts/preview_native.sh --editor
```

In a headless sandbox or CI, install the reproducible engine/toolchain:

```bash
bash tools/install_godot.sh 4.3-stable
export PATH="$HOME/.local/bin:$PATH"

godot --headless --path . --editor --quit
godot --headless --path . --script res://tools/runtime_expedition_probe.gd
```

See [`docs/GODOT_SANDBOX_SETUP.md`](docs/GODOT_SANDBOX_SETUP.md) for the local, sandbox, CI, export, and WebView workflow.

## Arena data and production direction

- [`data/organ_biomes/dermal_rift.json`](data/organ_biomes/dermal_rift.json) — runtime-authored anchor graph, route widths, state-specific anchor offsets, state cues, and safety contract.
- [`docs/PRODUCTION_ROADMAP.md`](docs/PRODUCTION_ROADMAP.md) — production gates for expanding this playable traversal slice into the full PHAGOS adventure.
- [`docs/preview/dermal_rift_layout_plan.png`](docs/preview/dermal_rift_layout_plan.png) — topology review image generated from the same authored data.

Pathogenic remains only a high-level public benchmark for readable organ identity and active biological space. PHAGOS uses no copied rooms, UI, content, or implementation. Details and sources are recorded in [`docs/REFERENCE_RESEARCH.md`](docs/REFERENCE_RESEARCH.md).
